# Comprobación de entrega

- [ ] Un proyecto elegido e integrantes identificados.
- [ ] Código Python, HTML, CSS y JavaScript completo.
- [ ] SQL de base, exactamente tres tablas, restricciones y semillas de la variante.
- [ ] Cuarto recurso, filtro del listado y al menos una prueba propia.
- [ ] requirements.txt, .env.example y README probado por otra persona.
- [ ] Flujo completo, errores y resumen verificados en el motor de entrega.
- [ ] Bitácora con implementación y revisión de cada integrante.
- [ ] PowerPoint comprensible sin ver el video.
- [ ] Video con aplicación ejecutándose y evidencia técnica individual.
- [ ] Subtítulos revisados y transcripción.
- [ ] Enlaces accesibles al docente.
- [ ] ZIP sin .env, .venv, cachés ni datos personales.
- [ ] Fuentes y limitaciones declaradas.
- [ ] Repositorio propio en GitHub con código visible y acceso verificado para el docente.
- [ ] Etiqueta v1.0-entrega y SHA entregados en el espacio del curso.
- [ ] Al menos un pull request técnico y una revisión por integrante.
