# comp2053
COMP 2053 Fullstack Development

## Proyecto fullstack de reservas

Construyan en pareja o en un trío una aplicación para reservar salas, prestar computadoras por hora o concertar tutorías. Los tres proyectos comparten las tablas `personas`, `recursos` y `reservas`. El catálogo y las etiquetas cambian según el proyecto elegido.

**Para empezar**, creen el repositorio de su equipo y sigan las instrucciones de la primera clase. [Inicio del proyecto](INICIO.md)

| Qué necesitan | Dónde encontrarlo |
|---|---|
| Tutorial, actividades por etapa y dos rúbricas | [Guía de clase](Leccion_fullstack.md) o [Word editable](Leccion_fullstack.docx) |
| Instalar y ejecutar la referencia con Flask | [Instrucciones de instalación](codigo/README.md) |
| Crear las tablas e insertar datos ficticios | [Scripts SQL para las tres variantes](codigo/sql/) |
| Distribuir el trabajo y anotar las pruebas | [Plantillas de trabajo](plantillas/) |
| Preparar el resumen del video | [Plantilla de PowerPoint](Plantilla_presentacion.pptx) |
| Identificar la versión entregada | [Ficha del equipo](ENTREGA.md) |

La primera nota evalúa el video con la aplicación en ejecución y el PowerPoint que explica el proyecto. La segunda nota evalúa el código, la instalación y el funcionamiento del proyecto. Cada nota vale 100 puntos. La entrega requiere una URL de GitHub accesible al docente y la versión que aparece en el video.
